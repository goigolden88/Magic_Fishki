# Решения

Голый «Р-NN» здесь — решение «Фишек». Решения конвейера — «Ш-NN» в `goigolden88/Shtab`.

### Р-01 · PWA без сервера: Vite + React + TypeScript, IndexedDB, GitHub Pages
09.10.2026

Приложение на телефоне, ставится с экрана браузера — и на iPhone (Safari → «Поделиться» → «На экран „Домой“»), и на Android; открывается и с компьютера. Работает без сети. Одно устройство ведёт игру — сервер не нужен. Выбор владельца 09.10.

### Р-02 · Курс фишки — у каждой игры свой; курс по умолчанию — в настройках
09.10.2026

Новая игра берёт курс из настроек (по умолчанию 0,5 ₽), его можно поменять при создании и до закрытия игры. Деньги — в копейках целыми. Выбор владельца 09.10.

### Р-03 · Переводы — жадно, от большего долга к большему выигрышу; несходящаяся игра переводов не считает
09.10.2026

Жадный расчёт даёт не больше «игроков − 1» переводов и понятен человеку. Если закупы и выходы не сходятся, переводы были бы неправдой — вместо них слова, сколько фишек не хватает.

### Р-04 · История — с демо-данными, не с реальными
09.10.2026

Для проверки — кнопка «Демо-данные» в настройках: несколько выдуманных игр, удаляются одной кнопкой (`demo: true`). Реальные игры в репо не попадают — он публичный. Выбор владельца 09.10.
