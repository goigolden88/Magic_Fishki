# Правила ревью

Замечания ревьюера, которые повторялись в PR «Фишек» (Ш-202 Штаба). Исполнитель сверяется с ними до PR, ревьюер — при проверке. Пополняет ретро или сессия Штаба, когда замечание встретилось второй раз; исполнитель этот файл не правит.

1. **Видимое — снимками.** Правка меняет экран — снимки на 390 px и широком окне в отчёте PR (`npm run shots`). Чего снимок не покажет (живая комната на двух телефонах, установка, звук, свёрнутое приложение) — шагами для человека в отчёте. Без снимков видимой правки — оговорка. (19 раз: `#124`…`#180`)
2. **Справка — вместе с экраном.** Кнопка, раздел или поведение на экране изменились — `helpText.ts` говорит то же; раздел справки — там, где кнопка на экране. (`#130`, `#132`, `#135`, `#180`)
3. **Копия данных.** Новая настройка или данные — в копию (`backup.ts`) и обратно; новый формат копии старое приложение не прочтёт — сказать в отчёте; что восстановление делает с уже выбранным на этом телефоне — сказать в отчёте. (`#119`, `#174`, `#178`, `#179`)
4. **Сервер и версия протокола.** Правка трогает сервер или общие правила стола — в отчёте: «после слияния сервер перевыкатится — сливать, когда никто не играет»; поднята версия протокола — что увидит старая копия на втором телефоне. (`#111`, `#118`, `#124`, `#175`)
5. **Иначе, чем в задаче.** Название, раскладка, значение не как в тексте задачи — не молча: строка в отчёте «сделал иначе, потому что…», а если это выбор для человека — `нужно-решение`. (`#160`, `#176`, `#177`)
6. **Меняется у всех.** Правка меняет привычное по умолчанию у тех, кто ничего не настраивал (кнопки ставок, вид, порядок) — первой строкой отчёта. (`#179`, `#180`)
