# Свой сервер покера

Как поднять свой сервер комнат для «Покера онлайн» — для своей компании, со своим паролем. Сайт «Фишек» остаётся тем же (`https://goigolden88.github.io/Magic_Fishki/`); своим становится только сервер, через который телефоны играют в одной комнате.

**Зачем.** Постоянный сервер — бесплатный план Cloudflare владельца «Фишек»: не больше 10 комнат разом и суточный предел запросов на всех. Свой сервер — свой предел, свой пароль компании, комнаты своей компании никто чужой не видит.

**Что нужно.** Аккаунт GitHub и аккаунт Cloudflare (бесплатный план, карта не нужна), компьютер — с телефона неудобно. Около 20 минут. Стол на одном телефоне сервер не использует — для него ничего этого не нужно.

## 1. Cloudflare: поддомен, номер аккаунта, ключ

1. Зарегистрироваться на `dash.cloudflare.com`.
2. Открыть **Workers & Pages** (левое меню, раздел Compute). При первом входе Cloudflare попросит выбрать поддомен `workers.dev` — выбрать (например, `masha`): из него получится адрес сервера.
3. Скопировать **Account ID** — справа на странице Workers & Pages (или в адресной строке: `dash.cloudflare.com/<Account ID>/…`).
4. Ключ: значок профиля справа вверху → **My Profile** → **API Tokens** → **Create Token** → шаблон **Edit Cloudflare Workers** → **Use template** → в «Account Resources» — свой аккаунт, в «Zone Resources» — **All zones** → **Continue to summary** → **Create Token**. Скопировать ключ: Cloudflare покажет его один раз.

Ключ — как пароль от сервера: никому не пересылать и никуда не вставлять, кроме шага 2.

## 2. GitHub: своя копия и два секрета

1. Открыть `github.com/goigolden88/Magic_Fishki` → **Fork** → **Create fork**. Получится своя копия `github.com/<ваш логин>/Magic_Fishki`.
2. В копии: **Settings** → **Secrets and variables** → **Actions** → **New repository secret**, два раза:
   - `CLOUDFLARE_API_TOKEN` — ключ из шага 1.4;
   - `CLOUDFLARE_ACCOUNT_ID` — номер из шага 1.3.
3. Вкладка **Actions** → **I understand my workflows, go ahead and enable them**.
4. Лишнее в копии выключить (сайт и агенты уже есть у владельца): в **Actions** слева выбрать **Выкладка** → «…» справа → **Disable workflow**; так же — **Агенты**.

## 3. Выкатить сервер

1. **Actions** → **Выкатка сервера покера** → **Run workflow** → **Run workflow**.
2. Подождать 2–3 минуты. Зелёная галочка — сервер выкачен. Красный крестик — открыть прогон и посмотреть шаг с ошибкой; чаще всего — неверно скопирован ключ или номер аккаунта (шаг 2.2) или не выбран поддомен (шаг 1.2).
3. Адрес сервера — `https://fishki-poker.<поддомен>.workers.dev` (поддомен из шага 1.2). Он же — в Cloudflare: Workers & Pages → `fishki-poker`.

## 4. Пароль компании

Без пароля сервер комнат не создаёт («На сервере не задан пароль»).

1. Cloudflare → **Workers & Pages** → `fishki-poker` → **Settings** → **Variables and Secrets** → **Add**.
2. Type — **Secret**, Variable name — `ROOM_PASSWORD`, Value — пароль компании → **Deploy** (или **Save**).
3. Пароль сообщить тем, кто будет создавать комнаты (ведущим). Остальным игрокам он не нужен — они входят по ссылке.

Пароль хранится только в Cloudflare: в копии на GitHub его нет, следующие выкатки его не стирают.

## 5. Проверка

Открыть в браузере адрес сервера из шага 3.3 — должна быть строка «Сервер покера «Фишек» работает, протокол N».

## 6. Адрес — в «Фишках», у каждого игрока

Ссылка на комнату адреса сервера не несёт: телефон идёт на тот сервер, что вписан у него в «Настройках». Поэтому адрес вписывает **каждый** игрок компании — и ведущий, и те, кто входит по ссылке:

«Фишки» → **Настройки** → **Покер онлайн** → **Адрес сервера** — вписать адрес из шага 3.3 → **Сохранить**.

Не вписал — по ссылке на комнату своего сервера телефон скажет «Комнаты нет» (он ищет её на постоянном сервере). Вернуться на постоянный сервер — очистить поле и сохранить.

## Обновление

Сайт «Фишек» обновляется сам, а сервер копии — нет. Когда в «Фишках» меняется покер, сайт начинает говорить с сервером новой версией, и старый сервер копии отвечает «Обновите приложение» — при создании комнаты или при входе.

Обновить: открыть свою копию на GitHub → **Sync fork** → **Update branch**. Выкатка сервера запустится сама (видно во вкладке **Actions**), через 2–3 минуты всё работает. Проверка — шаг 5: номер протокола вырос.

Во время выкатки идущая комната на несколько секунд теряет связь — телефоны переподключаются сами; надёжнее обновлять между вечерами.

## Если что-то не так

- **«Нет связи с сервером»** — неверный адрес в «Настройках» (шаг 6) или сервер не выкачен (шаг 3); или кончился суточный предел бесплатного плана — ждать до следующих суток (полночь по UTC, 03:00 по Москве). Стол на одном телефоне и учёт вечера от сервера не зависят.
- **«Неверный пароль»** — пароль у ведущего не тот, что в шаге 4.
- **«Комнат уже 10»** — на сервере 10 живых комнат; лишние закрыть у ведущего кнопкой «Закончить игру» (брошенные комнаты стираются сами через сутки без ходов).
- **Откат выкатки** — Cloudflare → Workers & Pages → `fishki-poker` → **Deployments** → у прошлой выкатки **Rollback**.
- **Удалить сервер** — Cloudflare → `fishki-poker` → **Settings** → **Delete**; копию на GitHub — **Settings** → внизу **Delete this repository**. Игроки очищают адрес в «Настройках».
