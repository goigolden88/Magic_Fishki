# Свой сервер покера

Как поднять свой сервер комнат для «Покера онлайн» — для своей компании, со своим паролем. Сайт «Фишек» остаётся тем же (`https://goigolden88.github.io/Magic_Fishki/`); своим становится только сервер, через который телефоны играют в одной комнате.

**Зачем.** Постоянный сервер — бесплатный план Cloudflare владельца «Фишек»: не больше 10 комнат разом и суточный предел запросов на всех. Свой сервер — свой предел, свой пароль компании, комнаты своей компании никто чужой не видит.

**Что нужно.** (Резерв на ноутбуке без аккаунтов — раздел «Сервер на ноутбуке — резерв» ниже.) Аккаунт GitHub и аккаунт Cloudflare (бесплатный план, карта не нужна), компьютер — с телефона неудобно. Около 20 минут. Стол на одном телефоне сервер не использует — для него ничего этого не нужно.

## 1. Cloudflare: поддомен, номер аккаунта, ключ

1. Зарегистрироваться на `dash.cloudflare.com`.
2. Открыть **Workers & Pages** (левое меню, раздел Compute). При первом входе Cloudflare попросит выбрать поддомен `workers.dev` — выбрать (например, `masha`): из него получится адрес сервера.
3. Скопировать **Account ID** — справа на странице Workers & Pages (или в адресной строке: `dash.cloudflare.com/<Account ID>/…`).
4. Ключ: значок профиля справа вверху → **My Profile** → **API Tokens** → **Create Token** → шаблон **Edit Cloudflare Workers** → **Use template** → в «Account Resources» — свой аккаунт, в «Zone Resources» — **All zones** → **Continue to summary** → **Create Token**. Скопировать ключ: Cloudflare покажет его один раз.

Ключ — как пароль от сервера: никому не пересылать и никуда не вставлять, кроме шага 2.

## 2. GitHub: своя копия и два секрета

1. Открыть `github.com/goigolden88/Magic_Fishki` → **Fork** → **Create fork**. Получится своя копия `github.com/<ваш логин>/Magic_Fishki`.
2. В копии: **Settings** → **Secrets and variables** → **Actions** → **New repository secret**, два раза:
   - `CLOUDFLARE_API_TOKEN` — ключ из шага 1.4;
   - `CLOUDFLARE_ACCOUNT_ID` — номер из шага 1.3.
3. Вкладка **Actions** → **I understand my workflows, go ahead and enable them**.
4. Лишнее в копии выключить (сайт и агенты уже есть у владельца): в **Actions** слева выбрать **Выкладка** → «…» справа → **Disable workflow**; так же — **Агенты**.

## 3. Выкатить сервер

1. **Actions** → **Выкатка сервера покера** → **Run workflow** → **Run workflow**.
2. Подождать 2–3 минуты. Зелёная галочка — сервер выкачен. Красный крестик — открыть прогон и посмотреть шаг с ошибкой; чаще всего — неверно скопирован ключ или номер аккаунта (шаг 2.2) или не выбран поддомен (шаг 1.2).
3. Адрес сервера — `https://fishki-poker.<поддомен>.workers.dev` (поддомен из шага 1.2). Он же — в Cloudflare: Workers & Pages → `fishki-poker`.

## 4. Пароль компании

Без пароля сервер комнат не создаёт («На сервере не задан пароль»).

1. Cloudflare → **Workers & Pages** → `fishki-poker` → **Settings** → **Variables and Secrets** → **Add**.
2. Type — **Secret**, Variable name — `ROOM_PASSWORD`, Value — пароль компании → **Deploy** (или **Save**).
3. Пароль сообщить тем, кто будет создавать комнаты (ведущим). Остальным игрокам он не нужен — они входят по ссылке.

Пароль хранится только в Cloudflare: в копии на GitHub его нет, следующие выкатки его не стирают.

## 5. Проверка

Открыть в браузере адрес сервера из шага 3.3 — должна быть строка «Сервер покера «Фишек» работает, протокол N».

## 6. Адрес — в «Фишках», у ведущего

Адрес вписывает только **ведущий** — тот, кто создаёт комнаты:

«Фишки» → **Настройки** → **Покер онлайн** → **Адрес сервера** — вписать адрес из шага 3.3 → **Сохранить**.

Ссылка на комнату сама несёт адрес этого сервера — и «Поделиться», и «Пересадить на новое устройство». Игрок открывает ссылку и попадает в комнату, ничего не вписывая у себя; на экране комнаты мелкой строкой видно «Сервер: …». Телефон помнит, на каком сервере его место, — после обрыва, перезапуска и из «Моих столов» идёт туда же.

Ссылка с испорченным адресом не откроется: «В ссылке неверный адрес сервера — попросите ведущего прислать ссылку заново». Вернуться на постоянный сервер — ведущему очистить поле и сохранить: новые ссылки пойдут без адреса.

## Сервер на ноутбуке — резерв

Если постоянный сервер не отвечает (кончился суточный предел, Cloudflare Workers лежит, аккаунт заблокирован), тот же код сервера запускается на любом ноутбуке — Windows, macOS или Linux, — без аккаунта Cloudflare и без своей копии на GitHub. Комнаты живут на ноутбуке, пока он включён: закрыл крышку — комнаты замерли. Ноутбук лучше подготовить заранее и один раз проверить: вечером без интернета Node.js не скачать.

**Подготовка — один раз** (≈ 15 минут, нужен интернет):

1. Поставить **Node.js** (версия LTS, `nodejs.org`) и **Git** (`git-scm.com`). Проверка — в терминале (Windows: «Пуск» → PowerShell) `node -v` и `git -v` печатают номера версий.
2. Скачать «Фишки» и всё нужное для сервера:
   ```
   git clone https://github.com/goigolden88/Magic_Fishki
   cd Magic_Fishki
   npm ci
   ```
3. Пароль компании — в файл `server/.dev.vars` (в репо он не попадает: файл в `.gitignore`). Windows, PowerShell: `Set-Content server\.dev.vars "ROOM_PASSWORD=ваш-пароль"`; macOS и Linux: `echo "ROOM_PASSWORD=ваш-пароль" > server/.dev.vars`.
4. Программа туннеля — даёт ноутбуку адрес `https://…`, без которого телефон к нему не подключится (сайт «Фишек» открыт по `https`, а браузер не пускает его к `http`): Windows — `winget install --id Cloudflare.cloudflared`, macOS — `brew install cloudflared`, Linux — пакет `cloudflared` с `github.com/cloudflare/cloudflared/releases`. Аккаунт не нужен.

**Вечером — запуск** (два окна терминала в папке `Magic_Fishki`):

1. Первое окно: `npm run server:local` — ждать строку `Ready on http://0.0.0.0:8787`. Окно не закрывать.
2. Второе окно: `cloudflared tunnel --url http://localhost:8787` — через 5–10 секунд в рамке появится адрес вида `https://слова-через-дефис.trycloudflare.com`. Окно не закрывать.
3. Ведущий: «Фишки» → **Настройки** → **Покер онлайн** → **Адрес сервера** — вписать этот адрес → **Сохранить** (как в шаге 6). Ссылка на комнату сама несёт адрес — игрокам ничего вписывать не нужно.
4. Ноутбук — в розетку и без сна: Windows — «Параметры» → «Система» → «Питание» → спящий режим «Никогда» (на вечер).

После вечера — `Ctrl+C` в обоих окнах, ведущий очищает адрес в «Настройках». Адрес туннеля новый при каждом запуске: старые ссылки на комнаты не откроются — ведущему создать комнату заново.

**Если не работает весь Cloudflare** (туннель тоже не запускается) — всё по домашнему Wi-Fi, без интернета вовсе:

1. Первое окно — `npm run server:local`, как выше. Второе — `npm run site:local`: ноутбук сам раздаёт сайт «Фишек»; ждать строку `Network: http://192.168.…:4173/Magic_Fishki/`.
2. Телефоны — в той же сети Wi-Fi, открыть в браузере адрес из строки `Network` (не приложение с экрана «Домой»).
3. Ведущий на этом сайте: **Настройки** → **Покер онлайн** → **Адрес сервера** → `http://<тот же 192.168…>:8787` → **Сохранить**.

Это другой адрес сайта, поэтому своих игроков, игр и вида стола там нет — только комната на вечер. Кнопка «Скопировать» ссылку может не сработать (браузер не даёт буфер обмена сайту по `http`) — ссылку показать с экрана или продиктовать код комнаты. Брандмауэр Windows при первом запуске спросит про доступ Node.js к сети — разрешить для частных сетей.

**Обновление.** Сайт «Фишек» обновляется сам, код на ноутбуке — нет. «Сервер старее приложения» — в папке `Magic_Fishki` выполнить `git pull` и `npm ci`, потом запустить заново. Проверять раз в месяц или перед вечером, где ноутбук может понадобиться.

## Обновление

Сайт «Фишек» обновляется сам, а сервер копии — нет. Когда в «Фишках» меняется покер, сайт начинает говорить с сервером новой версией, и старый сервер копии отказывает — при создании комнаты или за столом «Фишки» скажут: «Сервер старее приложения — ведущему обновить свой сервер (Sync fork)».

Обновить: открыть свою копию на GitHub → **Sync fork** → **Update branch**. Выкатка сервера запустится сама (видно во вкладке **Actions**), через 2–3 минуты всё работает. Проверка — шаг 5: номер протокола вырос.

Во время выкатки идущая комната на несколько секунд теряет связь — телефоны переподключаются сами; надёжнее обновлять между вечерами.

## Если что-то не так

- **«Нет связи с сервером»** — неверный адрес в «Настройках» у ведущего (шаг 6) или сервер не выкачен (шаг 3); или кончился суточный предел бесплатного плана — ждать до следующих суток (полночь по UTC, 03:00 по Москве). Стол на одном телефоне и учёт вечера от сервера не зависят.
- **«Неверный пароль»** — пароль у ведущего не тот, что в шаге 4.
- **«Комнат уже 10»** — на сервере 10 живых комнат; лишние закрыть у ведущего кнопкой «Закончить игру» (брошенные комнаты стираются сами через сутки без ходов).
- **Откат выкатки** — Cloudflare → Workers & Pages → `fishki-poker` → **Deployments** → у прошлой выкатки **Rollback**.
- **Удалить сервер** — Cloudflare → `fishki-poker` → **Settings** → **Delete**; копию на GitHub — **Settings** → внизу **Delete this repository**. Ведущий очищает адрес в «Настройках».
