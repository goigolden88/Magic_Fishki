# Архитектура

## Модель данных

```ts
type Game = {
  id: string            // ULID
  name: string          // «Пятница у Кирилла»; по умолчанию — дата
  date: string          // YYYY-MM-DD, день игры
  rate: number          // рублей за фишку: 0.5 — фишка по 50 копеек
  players: Player[]
  entries: Entry[]
  closed?: boolean      // игра закрыта: записи не правятся без «Открыть снова»
  demo?: boolean        // демо-данные — удаляются одной кнопкой
  updatedAt: string     // ISO 8601
}

type Player = { id: string; name: string }

type Entry = {
  id: string
  playerId: string
  kind: 'buyin' | 'rebuy' | 'cashout'
  chips: number         // целое, > 0
  at: string            // ISO 8601, ставится само
}

type Settings = { defaultRate: number }   // курс новой игры; по умолчанию 0.5
```

## Расчёт — `src/calc/`

- **Итог игрока:** `out − in`, где `in` — сумма закупов и докупов, `out` — сумма выходов (обычно один). В рублях — `× rate`, хранится и считается в копейках, округление — до копейки
- **Сходится ли игра:** сумма `in` всех = сумма `out` всех. Не сходится — итог показывает разницу словами и переводы не считает: «не хватает 500 фишек: у кого-то не записан выход»
- **Переводы:** жадно — самый большой должник платит самому большому получателю, пока все не на нуле. Переводов не больше «игроков с ненулевым итогом − 1». Проверка в тестах — пример со скриншота: 6 игроков, 5 переводов
- Всё — чистые функции с тестами

## Хранение

IndexedDB, база `magic_fishki`, версия 1: хранилища `games` (ключ `id`) и `settings` (одна запись). Новая версия — шагом миграции, старые записи не теряются.

## Экраны

- **Игры** — список, новые сверху; «Новая игра»
- **Игра** — участники; у каждого — записи и кнопки «Закуп», «Докуп», «Выход»; итог и переводы внизу
- **Настройки** — курс по умолчанию; «Демо-данные»: добавить / удалить

## Сборка и выкладка

Vite, `base: '/Magic_Fishki/'`; PWA — `vite-plugin-pwa` (манифест, работник, иконки, `apple-touch-icon` для iPhone). GitHub Pages — `.github/workflows/deploy.yml` на пуш в `main`.

## Структура кода

```
src/
  calc/       чистые функции: итоги, сходимость, переводы + тесты
  store/      db.ts — единственный вход в IndexedDB
  screens/    Games, Game, Settings
  app.tsx     маршруты (#/, #/game/:id, #/settings)
```
