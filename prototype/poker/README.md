# Прототип онлайн-покера владельца

Исходник для этапов покера (Р-14, #44): Node, сервер WebSocket на ноутбуке, клиент на чистом JS. Проверен владельцем: комната создаётся, друзья заходят по ссылке из браузера. Положен как есть, 16.10.2026; без `node_modules` и сохранённых комнат (`sessions/`).

Приложение его не собирает и не проверяет: `tsc` смотрит только `src/` корня, тесты `vitest` ищут файлы `*.test.*`, а здесь тесты — обычные скрипты Node.

## Что внутри

- `src/poker/engine.js` — одна раздача: ставки, банки и побочные банки (`pots.js`), «прогнать дважды»
- `src/poker/room.js` — комната и её настройки: стек, таймер хода, докупы, число мест, «прогнать дважды»
- `src/poker/format.js` — кэш или турнир; `session.js`, `storage.js` — сохранение комнаты в файл; `reconnect.js` — возврат игрока по токену
- `src/poker/stats.js` — статистика игроков: VPIP, PFR, AF и другие
- `src/poker/variants/` — техасский холдем; силу руки считает `pokersolver`
- `server.js` — сервер комнат (до 10 комнат, таймер хода, снимки)
- `public/` — клиент: `index.html`, `client.js`
- `test/` — сценарии Node: `node test/run-hand.js` и другие

## Запуск

```
cd prototype/poker
npm install
node server.js
node test/run-hand.js
```
